# Code of Conduct

## Expectations

Everyone participating in this project — issues, pull requests, discussions,
reviews — is expected to:

- Be respectful. Critique code and ideas, never people.
- Be honest. No fabricated results, benchmarks, or credentials.
- Be constructive. Reports of problems come with enough detail to act on.
- Respect privacy. Never post other people's private information, secrets,
  or non-public file contents — including in bug reports (redact first;
  `skillguard` itself masks secrets for exactly this reason).

## Unacceptable behavior

Harassment, discrimination, personal attacks, trolling, doxxing, and any
sexualized or violent language have no place here, in public or in private
channels related to the project.

## Reporting

Report conduct issues privately through GitHub's report-abuse tooling or by
opening a minimal issue asking a maintainer to make contact (do not include
sensitive details in the public issue). Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may
temporarily or permanently ban contributors for behavior they deem
inappropriate. Enforcement decisions include a short written rationale.
